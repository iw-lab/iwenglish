## 0. 진단 — 착수 시점의 격차

콘텐츠(352권·문장별 오디오·단어 타임스탬프)는 상용급인데 **학습 엔진이 콘텐츠를 못 따라가고 있었다.** 코드 전수 확인으로 찾은 5가지:

| # | 문제 | 근거 |
|---|------|------|
| G1 | **쉐도잉이 가짜** — 같은 문장을 2번 틀고 2회차에 겹쳐 말하기(합창 낭독). 진짜 쉐도잉은 원어민이 말하는 중 한 단어 뒤에서 따라가는 것 | 구 `Reader.tsx` passRef 2-pass |
| G2 | **치팅 자유** — 마지막 쪽으로 점프해 도장만 누르면 완독 + XP | 구 `onStamp` 무검증 |
| G3 | **말하기 검증 0** — 마이크 미사용. `modes.ts`가 광고하던 "발음 점수·내 목소리 비교"는 미구현 | 코드베이스 getUserMedia 0건 |
| G4 | **단어 학습이 자가신고** — "알아요" 연타로 무한 XP·박스 승급 | 구 `LearnClient.grade()` |
| G5 | **퀴즈가 장식** — 완독과 무관, 문항·답 위치 고정, 무한 재시도 | 구 `QuizPanel` |

부수 발견: `lib/srs.ts`(SM-2)는 어디서도 import되지 않는 데드코드였다 → 삭제.

**전략**: 이 격차를 뒤집은 것이 그대로 차별점이 된다 — *"검증된 학습(Verified Learning)": 진짜 듣고, 진짜 따라 말하고, 진짜 이해했을 때만 진도가 쌓이는 앱.*

## 1. 범위 결정 — 마이크(P3)를 왜 뺐는가

초안에는 VAD·STT·녹음비교(약 700줄)가 있었으나 **제외**했다.

1. **차별점이 아니다** — 발음 평가는 상용 영어앱의 레드오션이라 심사에서 변별력이 없다.
2. **데모 리스크가 가장 크다** — 기기별 AEC 편차, iOS Safari의 SpeechRecognition 불안정. 현장 시연이 깨지면 치명적이다.
3. **셀링 포인트에 불필요** — "검증된 학습"은 청취 커버리지 + 객관식 단어 + 이해 퀴즈만으로 성립한다.
4. **학습 효과는 측정이 아니라 수행에서 나온다** — 안 하는 아이는 마이크가 있어도 안 하고, 하는 아이는 없어도 한다.

대신 ⓐ 절약분을 쉐도잉 엔진 정교화에 투입했고 ⓑ `ReadSession.coverage`처럼 나중에 음성 지표를 붙일 스키마 자리를 비워뒀으며 ⓒ **거짓 광고가 된 `modes.ts` 문구를 실제 동작으로 정정**했다.

## 2. 설계 원칙

1. **검증은 엄격하게, 톤은 다정하게** — 차단 문구가 아니라 "아직 안 들은 문장이 8개 있어요! ▶ 이어서 읽기".
2. **기존 자산 재활용** — 전권이 이미 가진 `wordTimings`가 쉐도잉·커버리지의 공통 기반. 오디오 재생성 0건.
3. **소급 몰수 금지** — 기존 사용자의 도장·XP는 그대로 인정, 신규 세션부터 검증 적용.
4. **로컬 우선** — 모든 기록은 기기 안(localStorage). 서버 전송 없음.
5. **OpenNext 교훈 준수** — `prefetch={false}` 유지, `force-static` 금지.

## 3. 구현 결과

### P2 — 학습 무결성 (치팅 차단) ✅

- **문장 커버리지 추적**: 문장은 오디오가 `finish()`까지 실제로 재생됐을 때만 "들음"으로 인정. 페이지 점프·문장 탭·스킵으로는 절대 쌓이지 않는다. 마킹 지점은 `onEnd` 단 하나(단일 초크포인트).
- **도장 게이트** (`evaluateStamp`): 커버리지 90% 미만이면 도장 버튼 자체가 나오지 않고 "이어서 읽기"(첫 미청취 문장으로 점프)가 뜬다. 커버리지 링을 헤더·도장 카드에 상시 노출해 근거를 투명하게 보여준다.
- **마지막 도장 = 퀴즈 통과**: 10번째 도장(완독 왕관)은 이해 퀴즈 80% 이상을 요구한다.
- **완독 기록도 게이트**: `markFinished()`가 커버리지 미달이면 XP·세션 기록을 남기지 않는다.
- **퀴즈 강화**: 문항·보기를 매 시도마다 섞어 답 위치 암기를 차단.
- **단어 응답속도 가드**: 700ms 미만 응답은 박스는 갱신하되 XP·퀘스트 진척을 주지 않고, 완료 화면에서 "천천히 읽고 답해요"로 알린다.

### P1 — 진짜 쉐도잉 ✅

- **지연 추적(Delayed-Track)**: 오디오는 **한 번만** 끊김 없이 흐르고, 하이라이트 트랙을 2개 굴린다. 원어민(노랑 배경) / **내 차례(코랄 밑줄, `delayMs`만큼 뒤처짐)**. 불변식 `echoWord ≤ activeWord`를 유닛 테스트로 고정.
- **쉐도잉 사다리 5단계**: 듣기(에코 없음) → 같이 읽기(0ms) → 느린(800ms) → 표준(450ms) → 블라인드(300ms + 텍스트 가림). 단계별로 원어민 볼륨을 1.0 → 0.45로 감쇠해 내 목소리가 들리게 한다. 책별로 단계를 기억한다.
- **블라인드 모드**: 글자를 가리고 단어 길이만큼 칸만 남겨 "지금 말할 자리"만 색으로 알려준다(스크린리더용 텍스트는 유지).

### P4 — 어휘 학습 객관화 ✅

- **5가지 문제 유형 자동 생성** (`quizEngine.ts`, 기존 1000단어 데이터만 사용): 듣고 고르기 / 뜻 고르기 / 영어로 고르기 / 예문 빈칸 / 철자 조립.
- **박스별 난이도**: 박스 0~1은 인식(듣기·뜻), 2~3은 산출 초입(영작·빈칸), 4~5는 철자까지. 단어에 불가능한 유형(예문 없음·철자 9자 이상)은 자동 강등.
- **오답 보기**는 같은 레벨에서 우선 추출, 중복 제거.
- **정답 공개 카드**: 틀린 즉시 단어·뜻·예문·발음을 보여줘 그 자리에서 학습된다.
- Leitner 박스5(마스터)도 60일 뒤 망각 재검을 넣었다. 데드코드 `srs.ts` 삭제.

### P5 — 개인화·동기 ✅

- **레벨 진단**: 10문항(레벨당 2개)으로 시작 레벨 추천, 추천 레벨 카드에 ✨ 표시(잠금 없음 — 자율성 유지).
- **데일리 퀘스트 3종**: 책 1권 완독 / 단어 10개 맞히기 / 쉐도잉 5문장. 3개 완료 시 보너스 XP + **스트릭 프리즈**(하루 결석 면제권, 최대 3개) 지급 → 연속 붕괴로 인한 이탈 방지.
- **학부모 리포트** (`/progress` 보호자 탭): 최근 7일 막대그래프(단어·쉐도잉·책), 누적 지표, 그리고 검증 데이터라서 쓸 수 있는 한 줄 — *"지난 7일 동안 N일 학습했고, 책을 N권 끝까지 읽었어요. 쉐도잉으로 N문장을 따라 말했어요."*

### P6 — 마감 ✅

- **온보딩 3화면**: 그림책 / 진짜 쉐도잉 / 들은 만큼만 도장 — 앱의 약속을 먼저 말해준다.
- **문구 정직화**: `modes.ts`의 미구현 광고(발음 점수·내 목소리 비교·WPM 평가) 제거, 실제 동작으로 교체. `/learn` 부제도 플래시카드 → 문제 풀이로 수정.

## 4. 구현 중 실측으로 잡은 버그 2건

계획에 없었지만 브라우저 실측 과정에서 드러난 진짜 결함:

1. **날짜가 하루씩 밀림 (기존 버그)** — `addDays()`가 로컬 자정 Date를 `toISOString()`으로 포맷해 KST(+9)에서 항상 전날을 반환했다. 그 결과 ⓐ 학부모 리포트 7일 창에서 **오늘이 통째로 빠지고** ⓑ Leitner 복습 예정일이 하루 일찍 떴다. 로컬 기준 `ymd()/todayISO()/addDaysISO()`로 통일하고 회귀 테스트를 걸었다.
2. **백그라운드 탭에서 쉐도잉이 멈춤** — 화면이 꺼지거나 앱을 전환하면 `requestAnimationFrame`이 완전히 정지(실측: `visibilityState: hidden`에서 rAF 콜백 미발화). 에코 꼬리 처리가 rAF에만 의존해 문장 종료가 영영 안 잡히는 구조였다. **화면 갱신은 rAF, 종료 확정은 타이머**로 분리해 보장했다(무음 "혼자 읽기" 모드도 동일 처리).

## 7. 공모전 제출용 3줄 요약

1. **국내 유일 지연 추적 쉐도잉** — 오디오를 두 번 트는 "따라 읽기"가 아니라, 원어민이 말하는 중에 한 박자 뒤에서 겹쳐 말하게 하는 이중 하이라이트 엔진(5단계 사다리).
2. **도장이 곧 증명** — 문장을 끝까지 들어야, 마지막 도장은 이해 퀴즈까지 통과해야 찍힌다. 건너뛰기로는 아무 기록도 쌓이지 않는다.
3. **부모에게 숫자로 답한다** — "이번 주 우리 아이가 끝까지 읽은 책 N권, 따라 말한 문장 N개" — 검증된 데이터라서 쓸 수 있는 문장.
